localhost:5432 - This is the PostgreSQL database port. It's not meant to be accessed through a web browser. The "page not working" message is normal because it's a database connection port.
localhost:8108 - This is the Typesense search engine API. The "Not Found" message at the root endpoint is normal. You need to use specific API endpoints to interact with it.
localhost:8080 - This is your Rust web server, and it's now working correctly. We just confirmed this by getting a successful response from the health check endpoint.

Authentication endpoints (/api/v1/auth/):
1. Register a New User
Method: POST
URL: http://localhost:8080/api/v1/auth/register
Headers: Content-Type: application/json
Body (JSON):
{
    "username": "testuser",
    "email": "test@example.com",
    "password": "password123"
}

Terminal: docker exec -it postgres psql -U myuser -d postgres -c "SELECT * FROM users WHERE email = 'test@example.com';"

2. Login
Method: POST
URL: http://localhost:8080/api/v1/auth/login
Headers: Content-Type: application/json
Body (JSON):
{
    "email": "test@example.com",
    "password": "password123"
}
Response will include an Authorization header with a JWT token that you'll need for other endpoints

Terminal: docker logs rust-webserver 2>&1 | grep -i "login\|error\|auth" | tail -n 20

3. Request Password Reset
Method: POST
URL: http://localhost:8080/api/v1/auth/forgot-password
Headers: Content-Type: application/json
Body (JSON):
{
    "email": "test@example.com"
}

4. Reset Password
Method: PUT 
URL: http://localhost:8080/api/v1/auth/reset-password
Headers: Content-Type: application/json
Body (JSON):
{
    "token": "reset_token_received_via_email",
    "new_password": "new_password123"
}
